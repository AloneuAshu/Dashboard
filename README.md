# Peddapalle stage brief

Static dashboard for the Mancherial cluster inside Peddapalle: Chennur (SC), Bellampalli (SC), and Mancherial.

The first page is the stage brief. The roll tab holds age and sex ratio. Map and news holds the booth list and the saved publisher feed.

GitHub Pages serves the saved extract. Get latest runs only on the local Vite server, because that button starts a Python pull on this machine.

The voter-roll PDFs are not in this repository.
